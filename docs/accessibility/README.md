# Accessibility Governance

This directory is the machine-readable accessibility governance layer for
Clawix. It operationalizes Constitution IX.8 and `STANDARDS.md` for screen
reader behavior, keyboard navigation, focus order, visible focus, contrast,
reduced motion, text scaling, semantic labels, timed interactions, and UI
generated by agents.

Accessibility governance complements `docs/ui/`; it does not replace visual UI
authorization. Accessibility changes that alter presentation or user-visible
copy still follow `docs/adr/0010-interface-governance.md`.

## Files

- `capability-matrix.manifest.json`: required accessibility axes, source canon,
  public checks, and private/manual evidence boundaries.
- `surface-coverage.manifest.json`: visible surface to accessibility axis
  coverage, platform coverage, evidence aliases, and expiring gaps.
- `agent-generated-ui.manifest.json`: accessibility contract for SDK, custom,
  and generated UI.
- `source-detectors.manifest.json`: source patterns that classify
  accessibility-impacting changes.
- `completion-audit.md`: public-safe completion ledger for current evidence and
  EXTERNAL PENDING lanes.

## Required Workflow

1. Classify the UI change for accessibility impact.
2. Map touched visible surfaces to `surface-coverage.manifest.json`.
3. Declare affected axes and evidence in the PR/check output.
4. If the change alters visible copy, layout, motion, contrast, or hierarchy,
   also follow `docs/ui/` visual governance.
5. Keep real screen reader, signed-host, device, private capture, and human
   approval evidence outside the public repo; store only aliases and hashes.
6. Run `node scripts/accessibility_governance_guard.mjs` before closure.

## Public Check

```bash
node scripts/accessibility_governance_guard.mjs
```
