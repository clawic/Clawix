Clawix Style System
The centralized, platform-agnostic source of truth for how Clawix looks and moves. Every rule, token, component and screen is defined once here and shown live, so a change made here is meant to propagate outward to macOS, iOS, Android and web.
The standard
Foundations, components, iconography and mocked screens, all driven by one set of tokens. Nothing is hardcoded: change a token in tokens.css and it travels everywhere it applies.
The laboratory
A place to iterate on the visual language in isolation, before any change touches product code. Drift is captured as side-by-side discordances and resolved against a real visual reference, never by force.
