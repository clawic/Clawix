Foundations

The rules behind every component. Each card shows the rule, what it implies, and how it looks applied. The values live as tokens in ui.css, so changing one here changes the whole system.

Color & where it applies--accent · --ok · --warn · --danger · --strong
Blue is for signals only (links, subtle accents), never a primary button fill. Primary CTAs are solid dark (--strong). Green / amber / red are status only (done / running / error). Backgrounds stay clean, no warm tint.

Motion · curves--ease · --ease-inout · --ease-spring · linear
Four curves, each with one job — mirrors the macOS app. easeOut (--ease) is the default: hover, menus, panels. easeInOut (--ease-inout) is for things that open and close symmetrically: disclosures, content reflow. spring (--ease-spring, soft overshoot) is reserved for playful feedback: the toggle knob and toast. linear only spins (loaders, shimmer). The knobs below travel on each real curve.
--ease · easeOut — hover, menus, panels (the default)
--ease-inout · disclosures & reflow (symmetric)
--ease-spring · toggle & toast (soft overshoot)
linear · spinners & shimmer only
Motion · timing by interactionhover .12 · state .18 · menu .20 · panel .22 · disclosure .28
Speed is chosen by what is moving, never one duration for everything. Hover and press are the fastest so the UI feels instant; surfaces that carry more weight take longer. Dismissals are quicker than appearances (--dur-out .15s) so closing never lingers.
--dur-hover · .12s — hover / reveal / press --dur · .18s — generic state --dur-menu · .20s — popup open --dur-panel · .22s — panel / selection slide --dur-disclosure · .28s — expand / collapse --dur-out · .15s — dismiss

Motion · appear & disappearnudge-in + fade · fade-out · tooltip delay 1.5s
Transient surfaces emerge from their anchor and leave quietly. Menus, dropdowns and popovers appear with a 4px directional nudge + fade (--dur-menu) and disappear with fade only (--dur-out), never sliding back out. Hover-hints wait 1.5s (--delay-tip) before showing, so they never flash when the cursor just passes through. The toggle and toast carry the only bounce in the system. Try each below.

Elevation & hairline--shadow · --hairline ~8–10%
Hairlines are 0.5px at ~8–10% opacity; shadows are soft and only on things that truly float (popups, the composer, the window). Cards rest on a hairline, not a shadow.

Selection vs hover--sel 6% · --hover-soft 3.5%
Hover is always subtler than selection. A selected row sits at ~6% white overlay, a hovered row at ~3.5%, so the two never read the same. Lists keep a small gap so adjacent states don't touch.
