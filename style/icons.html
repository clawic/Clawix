Iconography

One line-icon set, shipped as a single SVG sprite (icons.svg) and referenced with <use href="icons.svg#i-name">. Icons inherit currentColor and a uniform 1.75 stroke with round caps and joins, so they read as one family at every size. On native platforms the same names map to the matching SF Symbol, keeping identical weight and meaning across macOS, iOS and Android.

1Sizing scale--ic 16 · s 13 · xs 11 · l 20

Four sizes, each with a job. Pick by the density of the surface, never arbitrarily. The point size is set by the class (.ic, .ic.s, .ic.xs, .ic.l), so an icon is the same size everywhere it plays the same role.

2Icons in contextalways currentColor

Icons take the color of their container: secondary on idle chrome, primary inside a solid button, status color when paired with a state. They are never tinted on their own.
