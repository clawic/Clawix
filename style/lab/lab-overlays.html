Drop-in patch for the canonical component (ui.css + app.js)
the fix, applied to the shared .pop-menu
/* ui.css */ .pop-menu{ position:fixed; z-index:4000; /* was absolute / z-index:30 */ } /* app.js — when a .dropdown opens, anchor its menu like lab.js place() */ function place(menu, rect){ var mh = menu.offsetHeight, vh = innerHeight, gap = 6; var up = (vh - rect.bottom) < mh + gap; menu.style.top = (up ? rect.top - gap - mh : rect.bottom + gap) + "px"; menu.style.left = rect.left + "px"; }
Because the workspace is shared right now, this patch is documented here rather than applied to ui.css / app.js directly. Drop it in when those files are free.
