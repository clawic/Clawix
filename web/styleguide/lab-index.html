Style System · Lab
An additive extension to the canonical pages: more components, every one interactive, plus a fixed-position overlay system so menus are never clipped. Built to be folded back into components.html / ui.css when the shared files are free.
The dropdown clipping bug is solved here. Every menu, popover, tooltip, modal, drawer, sheet and the command bar open as position:fixed anchored to their trigger, so an overflow:hidden ancestor or a later stacking context can no longer hide them. See the bug-vs-fix demo and the drop-in patch on the Overlays page.
